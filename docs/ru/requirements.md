## VPS

| | Минимум | Комфортно |
| --- | --- | --- |
| Система | Ubuntu 22.04 или 24.04, 64-bit | то же |
| Процессор | 1 vCPU | 2 vCPU |
| Память | 2 ГБ | 4 ГБ |
| Диск | 20 ГБ | 40 ГБ и больше (здесь лежат загруженные файлы) |
| Сеть | публичный IPv4-адрес | то же, от 100 Мбит/с |

- На минимальном VPS спокойно разговаривают около 10 человек одновременно. Демонстрации экрана на
  много зрителей важнее исходящая скорость канала, чем процессор.
- Выбирайте дата-центр поближе к большинству друзей: от этого зависит задержка голоса. Голосовые
  серверы в других местах можно добавить потом ([Голос](voice.md)).
- Нужен доступ по SSH с правами `root` (или `sudo`). Установщик работает и на VPS, где уже есть
  другие сайты за nginx (см. [Установка](install.md#vps-где-уже-есть-nginx)).

## Домен

Любой домен или поддомен, которым вы управляете, например `chat.example.com`. Создайте эти
DNS-записи у регистратора (или DNS-провайдера) **до** запуска установщика:

| Тип | Имя | Значение | Зачем |
| --- | --- | --- | --- |
| A | `chat.example.com` | IPv4-адрес VPS | сайт, API, приложения |
| A | `rtc.chat.example.com` | тот же адрес | голос и видео (не нужна, если ставите без голоса) |

Изменения DNS расходятся от минуты до часа. Проверка:

```bash
getent hosts chat.example.com rtc.chat.example.com
```

Обе строки должны показать адрес вашего VPS.

## Порты

Если включён `ufw`, установщик сам откроет их в нём. У многих хостеров есть ещё свой файрвол в
панели управления — откройте те же порты и там.

| Порт | Протокол | Зачем |
| --- | --- | --- |
| 80 | TCP | проверка Let's Encrypt, перенаправление на https |
| 443 | TCP | сайт, API, приложения, сигнализация голоса |
| 17881 | TCP | голос по TCP (запасной путь для строгих сетей) |
| 50000-50100 | UDP | звук и видео |
| 13478 | UDP | TURN (голос для тех, кто за строгим NAT) |

Если порт уже занят другой программой на VPS, установщик берёт следующий свободный и печатает
итоговый список в конце. По этому списку и открывайте файрвол хостера.

## На вашем компьютере

Ничего особенного: SSH-клиент (в Windows 10/11 `ssh` есть в PowerShell) и браузер. Приложение для
Windows — по желанию: AIDis работает в Chrome, Edge, Firefox и Safari, в том числе на телефонах.
