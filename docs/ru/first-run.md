# Первый запуск

[К README](../../README.ru.md) · [English](../en/first-run.md)

## Мастер настройки

Откройте ссылку, которую напечатал установщик: `https://chat.example.com/setup?code=...`. Пока мастер
не пройден, он открывается на любой странице сайта, а закончить его может только тот, у кого есть
код (он напечатан на VPS; `sudo cat /opt/aidis/Server/config/setup-code` покажет его снова).

1. **Код из установки.** Уже заполнен, если вы пришли по ссылке.
2. **Аккаунт администратора.** Логин (латинские буквы, цифры, `_`, `.` и `-`, от 2 до 32 символов),
   отображаемое имя, пароль (не короче 8 символов) и, по желанию, почта для сброса пароля в будущем.
3. **Первый сервер.** Название, например название вашей компании. Переименовать можно когда угодно.
4. **Регистрация.** Кто может создавать аккаунты:
   - **Выключена**: аккаунты создаёте только вы (Администрирование -> Пользователи);
   - **По приглашению**: любой с действующей ссылкой-приглашением на сервер;
   - **Открытая**: любой, кто откроет сайт.

   «По приглашению» и «Открытая» заработают после настройки почты, потому что новые люди
   подтверждают адрес ([Почта и регистрация](mail-and-registration.md)). До этого всё работает как
   «Выключена».

После **Завершить настройку** вы уже вошли и видите ссылку-приглашение на свой сервер. Скопируйте её
и отправьте друзьям. Мастер больше не появится: код перестаёт работать, а следующие посетители видят
страницу входа.

## Как пригласить людей

- Регистрация **по приглашению** или **открытая**: отправьте ссылку-приглашение; человек
  регистрируется по ней и после подтверждения почты сразу попадает на ваш сервер.
- Регистрация **выключена**: создайте аккаунты в **Настройки -> Администрирование -> Пользователи
  -> Создать** и отправьте каждому логин, начальный пароль и ссылку-приглашение.

Новая ссылка-приглашение: нажмите на название сервера слева вверху -> **Пригласить людей** (можно
ограничить число использований и срок).

## Администрирование

**Настройки (шестерёнка слева внизу) -> Администрирование** видно только администраторам:

| Раздел | Что там делать |
| --- | --- |
| Обзор, В сети, Хранилище | состояние сервисов, кто в сети, занятое место |
| Пользователи | создавать аккаунты, сбрасывать пароли, отключать аккаунты, назначать администраторов |
| Все серверы, Лимиты | все серверы этого AIDis, лимиты на новые серверы и загрузки |
| Почта, Регистрация | SMTP и режим регистрации |
| Голосовые серверы | дополнительные серверы LiveKit ([Голос](voice.md)) |
| Журнал | кто что менял |
| Объявление | баннер для всех |

Роли и каналы конкретного сервера — в его настройках (название сервера слева вверху ->
**Настройки сервера**).
