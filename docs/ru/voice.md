# Голос

[К README](../../README.ru.md) · [English](../en/voice.md)

## Как это устроено

Голос, видео и демонстрация экрана идут через **LiveKit** — открытый медиасервер, который работает на
вашем VPS рядом с AIDis. Браузер или приложение подключается к `wss://rtc.chat.example.com`, чтобы
войти в звонок, а звук и видео передаёт по UDP (порты 50000-50100) или, в сетях, где UDP закрыт, по
TCP (17881). Те, кто за очень строгим NAT, идут через встроенный TURN (UDP 13478). Больше никто не
участвует: звонки не покидают ваш сервер.

Установщик настраивает всё это с `--voice yes` (по умолчанию). В итоговом выводе перечислены порты;
они должны быть открыты в файрволе хостера.

## Включить или выключить голос позже

```bash
sudo bash /opt/aidis/deploy/setup.sh --voice yes     # или --voice no
```

С выключенным голосом LiveKit не работает и голосовые порты не нужны; его ключи остаются в
`Server/.env` на будущее. Для включения нужна DNS-запись `rtc.chat.example.com`.

## Проверка звонка

- Зайдите в голосовой канал со второго аккаунта (другой браузер или телефон) и поговорите.
- Полоски сигнала рядом с вашим именем показывают соединение; наведите на них, чтобы увидеть пинг.
- **Пинг «вычисляется», пока вы один и микрофон выключен**: статистика берётся из аудиопотоков, а их
  ещё нет. Включите микрофон или дождитесь собеседника.

## Дополнительные голосовые серверы

Друзьям, которые далеко от вашего VPS, достаётся большая задержка. Арендуйте небольшой VPS поближе к
ним и поставьте туда только голос:

1. DNS: `voice2.chat.example.com` -> новый VPS. **Это должен быть поддомен домена вашего AIDis**
   (приложения разрешают голосовые серверы только под ним).
2. Скопируйте `voice-node/install.sh` из этого репозитория на новый VPS и запустите:

   ```bash
   sudo bash install.sh --domain voice2.chat.example.com --email you@example.com
   ```

   Он работает как основной установщик: Caddy на чистом VPS, иначе уже установленный nginx, занятые
   порты сдвигаются. В конце напечатает три строки (URL, API key, API secret).
3. В AIDis: **Настройки -> Администрирование -> Голосовые серверы -> Добавить голосовой сервер**, вставьте три
   строки.
4. Перенесите туда голосовой канал: настройки канала -> **Голосовой сервер**.

`sudo bash install.sh --print` снова покажет три строки; `--uninstall` удалит узел. На том VPS
откройте: 80/tcp и 443/tcp (только с Caddy), 7881/tcp (или порт, который он выбрал) и
50000-60000/udp.

## Качество

Пресеты демонстрации экрана (от 720p30 до 1440p60) выбирает тот, кто показывает. Для 1080p VPS нужно
примерно 2-6 Мбит/с исходящей скорости на каждого зрителя. Звук лёгкий: около 50 кбит/с на каждого
говорящего для каждого слушателя.
