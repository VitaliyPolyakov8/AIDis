# Почта и регистрация

[К README](../../README.ru.md) · [English](../en/mail-and-registration.md)

AIDis отправляет письма для двух вещей: подтверждение почты нового аккаунта и сброс пароля. Без
почты всё остальное работает; аккаунты тогда создаёт администратор.

## Настройка почты (SMTP)

Нужен SMTP-доступ: почта вашего домена (её дают почти все регистраторы и хостинг-панели), почтовый
сервис для приложений или любой ящик, разрешающий вход по SMTP с паролем.

**Настройки -> Администрирование -> Почта**:

| Поле | Пример |
| --- | --- |
| SMTP-сервер | `smtp.example.com` |
| Порт и шифрование | `465` с TLS или `587` со STARTTLS |
| Логин, пароль | логин ящика и его пароль (или пароль приложения) |
| Имя отправителя | `AIDis` |
| Адрес отправителя | `noreply@example.com` (должен быть разрешён для этого логина) |

**Сохранить**, затем **Отправить тестовое письмо** на свой адрес. Почта считается рабочей только после
того, как тестовое письмо дошло (появится «Проверено ...»). Пароль хранится зашифрованным и больше не
показывается; оставьте поле пустым, чтобы его не менять.

Советы:

- Многие хостеры закрывают исходящий порт 25; используйте 465 или 587.
- Письма попадают в спам? Добавьте записи SPF и DKIM для домена отправителя, как описывает ваш
  почтовый сервис.
- Gmail и похожим сервисам нужен «пароль приложения», а не обычный пароль.

## Режимы регистрации

**Настройки -> Администрирование -> Регистрация**:

| Режим | Кто может зарегистрироваться | Нужна почта |
| --- | --- | --- |
| Выключена | никто; аккаунты создаёт администратор (Администрирование -> Пользователи) | нет |
| По приглашению | люди с действующей ссылкой-приглашением; после подтверждения почты они сразу на этом сервере | да |
| Открытая | любой, со страницы входа | да |

Новый аккаунт может войти только после подтверждения почты (ссылка действует 24 часа).

## Сброс пароля

С настроенной почтой на странице входа есть **Забыли пароль?**: ссылка (действует 1 час) приходит на
почту аккаунта. Без почты пароль сбрасывает администратор в **Администрирование -> Пользователи** и
передаёт новый человеку.

Свою почту люди меняют сами в **Настройки -> Мой аккаунт** (письмо с подтверждением уходит на новый
адрес).
