# Вопросы и ответы

[К README](../../README.ru.md) · [English](../en/faq.md)

**AIDis хоть как-то зависит от авторов?**
Нет. Нет центрального сервера, аккаунта или проверки лицензии. Всё работает на вашем VPS; приложение
обновляется с GitHub Releases (или с вашего зеркала).

**Сколько людей он выдержит?**
Он сделан для компаний друзей и небольших сообществ: десятки человек, около десяти одновременно в
голосе на VPS с 2 ГБ. Больше людей — больше VPS; голос можно разнести по дополнительным голосовым
серверам.

**Можно с телефона?**
Да, в браузере (Chrome, Safari). На iPhone и Android его можно добавить на главный экран, и он
ведёт себя как приложение. Отдельного мобильного приложения нет.

**Есть сквозное шифрование?**
Нет. Трафик шифруется между людьми и вашим сервером (HTTPS, DTLS/SRTP для звука и видео), а сервер —
ваш. Тот, кто управляет VPS, может прочитать базу.

**Несколько сообществ на одном AIDis?**
Да. Один AIDis держит много серверов, у каждого свои каналы, роли и приглашения. Аккаунты общие.

**Можно своё приложение под свой домен?**
Приложение универсальное: каждый вводит адрес своего сервера. Если нужны свои сборки, см.
[Свои сборки приложения](build-your-own-app.md).

**Где GIF и обложки из Steam?**
Выключены по умолчанию, потому что отправляют запросы сторонним сервисам. Включаются в `Server/.env`
(`GIF_PROVIDER`, `GIF_API_KEY`, `STEAM_ART=true`), затем `docker compose up -d` в `Server/`.

**Собирается какая-нибудь статистика?**
Нет. Никуда ничего не отправляется, пока вы сами не включите сторонние функции.

**Можно без Docker?**
Для разработчиков — да (см. [Server/README.md](../../Server/README.md)), но установщик и обновление
рассчитаны на Docker.
